2. Come Aggiungere il CSS (Focus: Inclusione dalla Pagina)

Il CSS controlla l'aspetto estetico della pagina. I tre metodi di integrazione si differenziano per scopo e collocazione:

1. CSS In-Page (Interno) ★

Inserito nella sezione <head> all'interno del tag <style>.

<head>
 <style>
  table { width: 100%; }
 </style>
</head>

Uso: Esercitazioni didattiche, prototipi rapidi, singoli documenti autonomi.

2. CSS In-Line

Applicato direttamente al singolo tag HTML tramite l'attributo style="...".

<td style="color: red;">
  Prezzo scontato
</td>

Uso: Eccezioni e override rari. Sconsigliato per codice pulito.

3. CSS Esterno

File .css separato collegato nella testata tramite il tag <link>.

<head>
 <link rel="stylesheet"
       href="style.css">
</head>

Uso: Standard professionale aziendale per siti multipagina.

Regola di Precedenza: Lo stile In-Line vince sempre; a parità di specificità tra In-Page ed Esterno, prevale la regola caricata per ultima.
